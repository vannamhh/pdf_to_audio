Key features:

Sidebar config: voice selector (5 presets VN/EN), speed slider, chunk size slider
Smart cleaning: auto header/footer detection, hyphenation fix, whitespace normalization
Text preview: expandable preview with word/char/page stats
Progress bar: real-time progress during audio generation
Audio playback: in-browser st.audio() player per chunk
ZIP download: one-click download of all parts

# How to Run

```bash
cd /Users/hoangnam/LocalSites/addon/convert_audio
source .venv/bin/activate
streamlit run app.py
```
